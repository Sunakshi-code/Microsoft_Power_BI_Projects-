# 🚕 Ola Ride Booking Analysis using Power BI

## 📌 Project Overview

An interactive Power BI dashboard for analyzing Ola ride booking data, including booking status, vehicle types, revenue, cancellations, payment methods, and customer and driver ratings.

## 🎯 Project Objectives

- Analyze booking performance and ride trends.
- Track successful, cancelled, and incomplete rides.
- Compare performance across vehicle types.
- Monitor booking value and payment methods.
- Explore customer and driver ratings.
- Identify cancellation patterns and reasons.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## 📊 Key Features

- DAX Measures for business calculations.
- Data cleaning and transformation using Power Query.
- Interactive dashboard with slicers and filters.
- Booking status and cancellation analysis.
- Vehicle-wise performance analysis.
- Revenue and payment method analysis.
- Customer and driver rating insights.

## 📈 Project Outcome

Built an interactive Power BI dashboard using DAX measures and Power Query to transform ride-booking data into meaningful business insights for decision-making.
